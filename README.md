# پلتفرم آموزش هوشمند چندوجهی (NeuroStudy AI Multimodal Tutor)

یک وب‌اپلیکیشن آموزشی پیشرفته و تعاملی مبتنی بر هوش مصنوعی ساخته‌شده با **Next.js (App Router)**، **TypeScript** و **Tailwind CSS** که به دانش‌آموزان و دانشجویان امکان می‌دهد مباحث درسی را به صورت متنی یا صوتی بپرسند و پاسخ‌ها را به‌صورت ترکیبی از **درس‌نامه گام‌به‌گام (همراه با فرمول‌های علمی KaTeX)**، **تصاویر و دیاگرام‌های مفهومی** و **پخش صوتی توضیحات (TTS)** دریافت نمایند.

---

## ✨ ویژگی‌های کلیدی پروژه

1. **ورودی چندگانه (Multimodal Input):**
   * امکان تایپ سوالات تک‌خطی یا طولانی با کلید `Enter` و `Shift + Enter`.
   * دکمه ضبط صدا با استفاده از وب‌استاندارد بومی مرورگر (`MediaRecorder`) و ارسال صوت برای رونویسی به متن (STT).
   * امکان آپلود فایل‌های متنی یا جزوات درسی (`.txt`, `.md`, `.py`, ...) جهت طرح پرسش روی محتوای فایل.
   * برچسب‌های سریع انتخاب موضوعات درسی (ریاضی، فیزیک، زیست‌شناسی، شیمی، برنامه‌نویسی).

2. **پاسخ‌دهی هوشمند چندوجهی (Multimodal Explanation Engine):**
   * نگارش توضیحات آموزشی شیوا با ساختار درسی و گام‌به‌گام.
   * پشتیبانی کامل از فرمول‌های ریاضی و فیزیک با کتابخانه **KaTeX** ($E = mc^2$ درون‌خطی و فرمول‌های بلوکی).
   * رندر بلوک‌های کد با امکان کپی مستقیم با یک کلیک.

3. **تولید و نمایش تصویر مفهومی (Visual Aid Generation):**
   * استخراج خودکار پرامپت تصویری دقیق متناسب با مبحث درسی.
   * تولید تصاویر و دیاگرام‌های باکیفیت و بدون واترمارک با هوش مصنوعی.
   * مودال لایت‌باکس تمام‌صفحه با قابلیت بزرگ‌نمایی و دانلود مستقیم تصویر.

4. **خروجی صوتی روان (Text-to-Speech Player):**
   * تولید فایل صوتی توضیحات درس به زبان فارسی.
   * پلیر اختصاصی با دکمه‌های Play/Pause، نوار جابجایی زمان (Seekbar)، قطع/وصل صدا و تغییر سرعت پخش (`0.75x`, `1x`, `1.25x`, `1.5x`, `2x`).

5. **مدیریت تاریخچه و جلسات آموزشی:**
   * ذخیره تاریخچه گفتگوها در حافظه مرورگر (`localStorage`).
   * امکان ایجاد گفتگوی جدید (New Chat) و حذف گفتگوهای گذشته.
   * طراحی ریسپانسیو و پشتیبانی کامل از جهت راست‌چین (RTL) و فونت وزیرمتن.

├── .env.example                 # نمونه متغیرهای محیطی
├── .env.local                   # کلیدهای محرمانه API

├── tailwind.config.ts

## 🚀 راهنمای نصب و اجرا

### ۱. پیش‌نیازها
* داشتن **Node.js** نسخه ۲۰ یا بالاتر و **npm**.

### ۲. نصب پکیج‌ها
```bash
npm install
```

### ۳. تنظیم کلیدهای API (اختیاری اما پیشنهادی)
فایل `.env.example` را بررسی کرده و مقادیر مورد نیاز را در `.env.local` وارد نمایید:
```env
# کلید API جمینای (پیشنهادی)
GEMINI_API_KEY="AIzaSy..."

# یا کلید API اوپن‌ای‌آی
OPENAI_API_KEY="sk-..."

# مدل پیش‌فرض متنی
AI_TEXT_MODEL="gemini-2.5-flash"
```
*(نکته: پروژه طوری طراحی شده است که در صورت نبود کلید API نیز با سیستم Fallback و سرویس‌های در دسترس به طور کامل کار می‌کند).*

### ۴. اجرای نسخه توسعه (Development)
```bash
npm run dev
```
سپس آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

### ۵. ساخت نسخه تجاری (Production Build)
```bash
npm run build
npm run start
```
