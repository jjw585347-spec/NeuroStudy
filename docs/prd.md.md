# سند نیازمندی‌های محصول (PRD) - دستیار آموزشی چندوجهی (Multimodal AI Tutor)

## ۱. معرفی و هدف پروژه
هدف این پروژه طراحی و پیاده‌سازی یک وب‌سایت آموزشی تعاملی است که در آن کاربران می‌توانند سوالات درسی خود را (به‌صورت تایپ یا صدا) بپرسند و هوش مصنوعی مفاهیم را با ترکیب **توضیحات متنی ساده، تولید تصاویر/نمودارهای آموزشی و پخش صوتی** آموزش دهد.

---

## ۲. ویژگی‌های کلیدی (Core Features)
1. **ورودی چندگانه (Multimodal Input):**
   - امکان تایپ سوال یا آپلود متن درسی.
   - امکان ضبط صدا و تبدیل گفتار به متن (Speech-to-Text) برای پرسیدن سوال.
2. **پاسخ‌دهی هوشمند و آموزشی (AI Explanation Engine):**
   - تحلیل سطح سوال و ارائه پاسخ گام‌به‌گام، روان و آموزشی (با پشتیبانی از فرمول‌های ریاضی/علمی و بلوک‌های کد).
3. **تولید و نمایش تصویر آموزشی (Visual Aid Generation):**
   - تشخیص خودکار نیاز به تصویرسازی در پاسخ و تولید تصویر، نمودار یا اینفوگرافیک مرتبط با موضوع درسی توسط هوش مصنوعی.
4. **خروجی صوتی (Text-to-Speech):**
   - قابلیت پخش صوتی توضیحات متنی با صدای طبیعی و امکان کنترل پخش (پخش، توقف، تغییر سرعت).
5. **رابط کاربری چت‌محور و تعاملی (Interactive UI):**
   - محیط کاربری تمیز، واکنش‌گرا (Responsive) و مناسب برای مطالعه، همراه با تاریخچه گفتگوها.

---

## ۳. استک فنی پیشنهادی (Tech Stack)
*(ایجنت باید در مرحله ارائه نقشه، انتخاب نهایی این موارد را به تایید کاربر برساند)*
- **Frontend:** Next.js یا React + Tailwind CSS (برای طراحی سریع، مدرن و واکنش‌گرا)
- **Backend:** Node.js (Express/Next.js API Routes) یا Python (FastAPI)
- **AI Services:** 
  - مدل زبانی (LLM) برای تولید توضیحات درسی و پرامپت تصویر
  - مدل تولید تصویر (Image Generation API) برای ساخت تصاویر آموزشی
  - سرویس تبدیل متن به گفتار (TTS) و گفتار به متن (STT)
